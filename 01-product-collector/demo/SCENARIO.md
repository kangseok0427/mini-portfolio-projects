# 25초 상품 수집 데모

| 시간 | 화면 | 자막 |
|---|---|---|
| 0~3초 | 수집 결과표와 Excel 다운로드 버튼 | 상품정보 복사, 한 번에 끝내세요 |
| 3~7초 | 모드·URL 입력 | 공개 상품 페이지 URL 입력 |
| 7~15초 | 실제 공개 웹페이지 수집 버튼과 진행률 | 상품명·가격·링크 자동 정리 |
| 15~21초 | 결과표·저장 건수·Excel 다운로드 | 정리된 Excel 자동 생성 |
| 21~25초 | Excel 표 | 우리 업무에 맞춘 자동화 개발 가능 |

오프라인 시연에는 샘플 모드를 사용하고 화면에 “샘플 데이터 데모”를 표시합니다. 샘플은 정상 5건·중복 1건·잘못된 가격 1건입니다. 실제 웹 시연은 Books to Scrape 1페이지 20건을 사용합니다.

스크린샷 3장: (1) URL 입력 화면, (2) 완료 결과표와 요약, (3) 필터와 가격 열이 보이는 Excel. `screenshots/`에 실제 앱 화면을 담습니다.
