# 실제 Discord 촬영 순서 (약 45초)

개인 테스트 서버에서만 진행합니다. 봇 토큰·환경 파일·개인 DM은 화면에 띄우지 않습니다.

1. 0–5초: `/setup` 안내 패널. 자막: “역할 선택부터 비공개 문의까지”.
2. 5–12초: 일반 계정으로 회원 역할 버튼 클릭. 프로필 역할 변화를 보여 줍니다.
3. 12–22초: 문의 버튼 클릭 → 비공개 채널 생성. 다시 눌러 같은 채널로 안내되는지 확인합니다.
4. 22–28초: 두 번째 일반 계정에서는 문의가 안 보이는지 확인합니다.
5. 28–35초: 봇 재시작 후 기존 버튼을 다시 눌러 기존 문의를 찾는지 확인합니다.
6. 35–42초: 운영진으로 문의 종료 → 작성자에게 채널이 사라지고 운영진에게 남는지 확인합니다.
7. 42–45초: `/audit` 처리 시각·역할 지급·문의 생성·종료 기록을 보여 줍니다.

필수 스크린샷: 안내 패널 / 비공개 문의 권한 / 종료 후 처리 기록.
자동 테스트 출력은 실제 Discord 화면을 대신하는 영상으로 표시하지 않습니다.
