# 35초 문서 분석 데모

| 시간 | 화면 | 자막 |
|---|---|---|
| 0~3초 | 답변과 문서 출처 | 회사 문서, 답과 근거를 함께 |
| 3~10초 | 계약서·변경 제안서·PDF 복수 업로드 | 문서 3개를 검색 가능한 상태로 |
| 10~20초 | “계약 기간은 언제까지야?” 입력 | 문서에 자연어로 질문 |
| 20~28초 | 답변과 [S1] 출처 펼치기 | 계약서의 원문·페이지 확인 |
| 28~35초 | “두 문서의 차이를 정리해줘.” | 우리 회사 문서에 맞춘 AI 개발 |

실제 생성 답변 촬영은 `LLM_PROVIDER=api`와 본인 API 키를 설정합니다. 키 없는 검색 데모에는 “로컬 검색 데모 · LLM 호출 없음” 문구를 유지합니다.

스크린샷 3장: (1) 문서 3개와 검색 구간 수, (2) 계약 기간 질문/답변, (3) 원문 출처가 펼쳐진 비교 답변.
