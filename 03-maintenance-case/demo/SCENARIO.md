# 30초 BEFORE / AFTER 영상

| 시간 | 화면 | 자막 |
|---|---|---|
| 0~3초 | BEFORE 중단 / AFTER 완료 | 멈추던 프로그램, 고쳐드립니다 |
| 3~10초 | BEFORE 실행 → 503 → 부분 CSV | 오류 하나에 전체 중단 |
| 10~20초 | AFTER 실행 → 자동 재시도 | 오류 처리·중복 제거·정상 저장 |
| 20~26초 | 정상 5건·Excel 다운로드 | 필요한 기능도 함께 추가 |
| 26~30초 | 비교 화면 | 기존 프로그램 수정·유지보수 문의 |

스크린샷 3장: (1) 비교 초기 화면, (2) BEFORE 오류 로그와 부분 저장, (3) AFTER 완료·재시도·Excel 다운로드. 화면의 “오류 주입 데모” 표시를 유지하고 실제 고객 작업 사례로 설명하지 않습니다.
