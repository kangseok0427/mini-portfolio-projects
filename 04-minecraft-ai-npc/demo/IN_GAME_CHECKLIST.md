# 실제 서버 검증·촬영 체크리스트

이 목록은 자동 테스트 결과가 아니라 운영자가 실제 게임에서 확인할 항목입니다. 촬영 전에 빈 테스트 월드에서 진행하세요.

- [ ] Java 25 / Paper 26.2로 서버 시작, GaonAINPC 활성화 로그 확인.
- [ ] OP가 `/ainpc create merchant 상인 가온` 실행, 주민 한 명·이름 표시 확인.
- [ ] 우클릭 시 거래창이 열리지 않고 대화 안내가 보이는지 확인.
- [ ] 일반 채팅 질문이 전체 채팅에 공개되지 않고 NPC 답변이 본인에게만 보이는지 확인.
- [ ] “철 어디서 구해?” 후 3초 기다리고 “아까 뭐 찾았지?”로 기억 확인.
- [ ] 두 번째 플레이어의 같은 질문에 첫 플레이어 기록이 섞이지 않는지 확인.
- [ ] guide NPC 생성 후 같은 플레이어의 상인 대화가 섞이지 않는지 확인.
- [ ] `/ainpc exit` 후 일반 채팅이 복구되는지 확인.
- [ ] 기억 off/clear·성격 변경 후 이전 기록이 사라지는지 확인.
- [ ] 이름 변경, NPC 삭제, 관리자 권한 없는 플레이어의 관리 명령 거절 확인.
- [ ] 서버 재시작 후 NPC가 중복 생성되지 않고 대화 기억이 복원되는지 확인.
- [ ] API 모드: 실제 모델·환경변수 키 설정 후 답변과 기억 확인.
- [ ] 잘못된 키·API 주소·타임아웃으로 대화 실패 안내 확인, 서버의 다른 활동은 계속 가능한지 확인.
- [ ] 긴 메시지·빠른 반복 요청이 제한되는지 확인.
- [ ] 응답 대기 중 NPC 삭제·기억 clear 시 늦은 답변이 기록을 되살리지 않는지 확인.
- [ ] 화면에 API 키·개인 서버 주소·다른 플레이어 정보가 없는지 확인 후 촬영.

발견한 문제는 Paper 빌드·Java 버전·명령·서버 로그와 함께 기록하세요. 유료 API를 쓰는 테스트는 해당 제공자 요금이 발생할 수 있습니다.
