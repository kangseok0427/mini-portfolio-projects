# 40초 포트폴리오 데모 / 40-second showcase

첫 3초 자막: **“아까 나눈 대화를 기억하는 Minecraft NPC” / “A Minecraft NPC that remembers you”**

준비: Paper 서버에 플러그인 설치, 상인 주민 1명 생성, 기억 켜기, 낮 시간·조용한 공간. 생성형 AI 영상은 API 모드에서 촬영. 로컬 모드는 화면의 DEMO 라벨을 유지하고 “대본 기반 로컬 데모” 자막을 넣는다.

| 시간 | 장면 | 자막 |
| --- | --- | --- |
| 0–3초 | 이름이 있는 상인 주민과 대화 화면 | 대화를 기억하는 AI NPC |
| 3–8초 | `/ainpc create merchant 상인 가온` 또는 생성 완료 장면 | 원하는 위치에 NPC 생성 |
| 8–13초 | 성격 merchant·기억 on 설정, 주민 우클릭 | NPC마다 다른 성격 |
| 13–23초 | “철 어디서 구해?” → 상인의 답변 | LLM과 자연어 대화 |
| 23–34초 | “내가 아까 뭐 찾는다고 했지?” → 철을 찾던 질문 회상 | 플레이어별 대화 기억 |
| 34–40초 | 다른 NPC 또는 기억 clear 명령, 문의 자막 | Minecraft 플러그인·AI 연동 제작 |

API 응답이 길면 실제 응답 장면 사이를 편집하되 대기 구간을 줄였다는 사실을 설명란에 적는다. 코드 화면·가짜 게임 화면을 실제 플레이 영상처럼 사용하지 않는다.

## 스크린샷 포인트 3장
1. **NPC 생성:** 이름이 보이는 주민, 성공 명령 안내, 실제 월드.
2. **첫 대화:** 철을 묻는 플레이어 질문과 상인 답변. DEMO/API 모드가 보이게 한다.
3. **기억 회상:** 두 번째 질문과 첫 질문을 기억하는 답변이 한 화면에 보이게 한다.

추천 썸네일: “이 NPC는 당신을 기억합니다” / “Your NPC remembers you.”

설명란: “Paper 플러그인 데모. NPC 성격 설정·플레이어별 기억·API 연동·기존 플러그인 수정 작업을 의뢰할 수 있습니다.”
